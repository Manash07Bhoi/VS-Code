# Search Engine Optimization and Indexing Policy

## 1. Scope

SEO applies to public product information. Authenticated workspace, editor, private reports and history must not be indexed or exposed through public caching.

## 2. Public content

Use clear title, concise meta description, semantic headings and descriptive links. Explain accurately: AI-assisted code review, explanations and history. Do not claim guaranteed bug detection, complete security audit, superior benchmarks or customer adoption without evidence.

## 3. Technical SEO

- Serve crawlable public content where appropriate.
- Use canonical URLs for indexable pages.
- Exclude private application paths from indexing.
- Generate a sitemap only for real public pages.
- Keep redirects intentional and non-looping.
- Add social metadata when useful.
- Use original favicon and accurate application metadata.
- Synchronize metadata with actual page content.

## 4. Private routes

`noindex` is not a replacement for authentication. Private pages require server-side auth and authorization. Never expose private report/source in public previews. Set cache headers to prevent shared caching.

## 5. Structured data

Use structured data only when page qualifies and information is real. Do not add fabricated ratings, reviews, pricing, customer proof or unsupported product claims. Validate data before release.

## 6. Quality overlap

Use semantic markup, optimized assets, useful links and stable layout. Do not put essential text only in images. SEO must never weaken privacy or security.

## 7. Verification

Inspect rendered HTML, robots directives, sitemap, canonical metadata, redirects and private response headers. Verify private routes reject unauthenticated access. Record actual checks rather than assuming source markup is correct.
