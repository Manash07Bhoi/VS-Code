## Recommended Arena reading order

1. Master prompt and `AGENT.md`.
2. `README.md` and actual repository inspection.
3. `REPOSITORY-AUDIT.md`.
4. `PRD.md` then `PRD2.md`.
5. Screens, UX flows, conditional logic and website flow.
6. Design system, wireframes and desktop gestures.
7. Architecture, DB, API and security.
8. Error states, notifications, performance, accessibility and SEO.
9. Testing, CI/CD, SOP, deployment and pre-release.
10. Update changelog and index if docs change.

## Governance

These documents are requirements/guidance, not proof of implementation. Arena updates status using actual repository evidence. Deferred features are identified with rationale. Add cross-links for new docs. No file may be empty, token-sized or just a list of headings.
